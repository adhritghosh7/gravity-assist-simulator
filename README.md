# 3-Body Gravity Assist Simulator
## What the code actually does:
This project aims to model how graviatational interactions between the Sun, a planet and a spacecraft affects the spacecraft's trajectory. The main goal is to see how a sapcecraft can affectly use the gravitational field of a planet to propel itself in space.

## Project Overview
When a spacecraft travels thorugh a solar system, it can use the gravitational fileds of planets to change its velocity and trajectory. This technique is called gravity assist or gravitational slingshot, allowing the spacecraft to gain or lose energy whitout relying on onboard propulsion.
